## Server changes needed

- **UXP1-S013:** the board route's `unitHealth[].health` comes only from the unit's latest report. To make the rule server-side, let open escalations and an exhausted budget raise a unit's health, or add a field such as `needsAttention` to each `unitHealth` row so every client gets it. The dashboard works it out from `openEscalations` and `overBudget` for now.
- **UXP1-S016:** the validate route answers `OneRoot` with no unit and the message "An organization needs at least its root unit." for an empty tree (`OrgTreeValidator.cs` line 230). The dashboard now handles it, but a separate code (for example `NoRootUnit`) would let clients tell "no root" from "two roots" without checking for a missing unit.
